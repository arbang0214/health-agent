# 운동 일지 + AI 코치 설계 (2026-07-30)

## 목적

운동 사진(스탯)만 기록하던 RunLog에 **그날 어떻게 뛰었는지(자유 텍스트 일지)** 를 남기고,
쌓인 기록을 모아 **운동 효과 분석 + 다음 목표치 + 운동 방법 제안**을 받는 기능을 추가한다.

- 입력: 자유 텍스트 한 줄 (예: "300m 뛰고 200m 걷기 5번 반복, 마지막에 힘들었음")
- 분석: 사용자가 원할 때 버튼으로 요청 (자동 아님)
- 로그인 없는 현재 구조 유지 (신원 필요한 기능 없음)

## 범위 밖 (YAGNI)

- 공유/좋아요/응원 기능 (로그인 필요라 보류)
- 일지의 구간 데이터 구조화 (AI가 텍스트를 직접 읽음)
- 저장 시 자동 피드백 (버튼 분석만)

## 데이터 모델

### `workouts` 컬럼 추가

```sql
alter table workouts add column journal text;
```

- null 허용. 일지 없는 기존/신규 기록 모두 정상 동작.

### 새 테이블 `coach_reports`

```sql
create table coach_reports (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz not null default now(),
  content text not null  -- 분석 리포트 마크다운 전문
);
```

- 지난 리포트 재열람 + 다음 분석 시 "직전 제안" 입력으로 재활용.
- **일일 호출 한도**: 별도 테이블 없이 `coach_reports`에서 오늘 생성된 행 수 ≥ 5면 거부.

마이그레이션 파일: `docs/migrations/2026-07-30-add-journal-coach.sql`
(기존 관례대로 사용자가 Supabase SQL Editor에서 직접 실행)

## 화면 흐름

| 화면 | 변경 |
|---|---|
| `/upload` | 스탯 입력 아래 선택 입력칸 "오늘 어떻게 뛰었나요? (선택)". placeholder: "300m 뛰고 200m 걷기 5번 반복" |
| `/day/[date]` | 일지 표시 + 스탯처럼 인라인 수정 |
| `/coach` (신규) | "분석해줘" 버튼 → 로딩 → 최신 리포트 표시. 아래에 지난 리포트 목록(날짜별 접기) |
| `/` (홈) | 코치 페이지로 가는 카드/링크 추가 |

## 분석 API — `POST /api/coach`

Next.js route handler (Vercel 서버 실행). 흐름:

1. `coach_reports`에서 오늘 생성 수 확인 → 5회 이상이면 **429** ("오늘 분석 횟수를 다 썼어요, 내일 다시!")
2. 최근 8주 `workouts`(스탯 + journal)와 **직전 리포트 1건**을 모아 프롬프트 구성
3. Claude API 호출
   - 모델: `claude-opus-5`, SDK: `@anthropic-ai/sdk`
   - API 키: Vercel 환경변수 `ANTHROPIC_API_KEY` (로컬은 `.env.local`, 커밋 안 함)
   - 시스템 프롬프트: 한국어 러닝 코치. ① 운동 효과 분석 ② 다음 목표치 ③ 구체적 운동 방법(인터벌 구성 등)을 마크다운으로
   - 안전 분류기 거부 시 자동 대체 모델 재실행: `fallbacks: "default"` (beta `server-side-fallback-2026-07-01`)
4. 결과를 `coach_reports`에 insert 후 반환

**비용**: 회당 약 3~4천 토큰 → 약 50~80원/회. 일일 5회 한도로 하루 최대 ~400원 캡.

**타임아웃**: 분석 호출 10~30초 가능 → 라우트에 `export const maxDuration = 60` 설정.

## 에러 처리

| 상황 | 처리 |
|---|---|
| 기록 0건 | 400 "분석할 기록이 아직 없어요" |
| 일지 없이 스탯만 | 분석 가능 (일지가 있으면 더 정확하다고 리포트에서 안내) |
| 일일 한도 초과 | 429, 한도 차감 없음 |
| Claude API 실패 | 502 + 한국어 안내, 리포트 저장 안 함 (실패는 한도 미차감 — 저장 기반 카운트라 자동 충족) |

## 테스트 (Vitest)

- `src/lib/coach-prompt.ts` — 프롬프트 빌더 순수 함수 분리: 기록 배열(+직전 리포트) → 프롬프트 문자열. 기록 0건/일지 유무 혼재 케이스 포함
- 일일 한도 판정 로직 (오늘 날짜 경계)
- `/api/coach` 라우트는 Claude 호출 모킹

## 결정 로그

- 공유+응원 → 로그인 필수라 보류, 대신 사용자 아이디어인 일지+코칭으로 전환
- 입력은 자유 텍스트 (입력 부담 최소화 > 데이터 정밀도)
- 분석은 온디맨드 버튼 (비용 통제, 주 1회 사용 패턴)
- 리포트 저장 (코칭 연속성: "지난번 대비" 비교)
- 공개 엔드포인트 비용 방어: 일일 5회 서버 강제 한도
