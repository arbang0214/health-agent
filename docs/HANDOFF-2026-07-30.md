## 2. 남은 필수 작업 (이 순서대로)

**⚠️ ①·②가 끝나기 전까지 배포된 앱에서 새 기능은 동작하지 않는다**
(일지를 입력한 저장은 에러, /coach 분석은 실패 메시지 — 기존 사진 업로드·캘린더는 정상).

1. **Supabase 마이그레이션 실행**
   https://supabase.com/dashboard/project/wjaifunxiwrunceggmmh/sql/new 에서
   `docs/migrations/2026-07-30-add-journal-coach.sql` 내용 붙여넣고 Run.
   확인: Table Editor에 `coach_reports` 생성, `workouts`에 `journal` 컬럼.

2. **Anthropic API 키 발급·등록**
   - https://platform.claude.com → Settings → API Keys → Create Key (크레딧 필요, $5면 충분)
   - 로컬: `.env.local`의 `ANTHROPIC_API_KEY=` 뒤에 키 입력 (커밋 금지 — gitignore 처리됨)
   - Vercel: health-agent-beta → Settings → Environment Variables → `ANTHROPIC_API_KEY` 추가(Production)
   - Vercel 환경변수는 다음 배포부터 적용 → 등록 후 **Deployments에서 Redeploy** 한 번

3. **스모크 테스트 (폰)**
   - 일지 포함 업로드 → 날짜 상세에서 📝 표시·수정
   - `/coach` 분석 1회 → 리포트 생성 확인
   - (선택) 6번째 분석 시도 → "오늘 분석 횟수를 다 썼어요" 429 확인
   - 예전부터 미확인이던 HEIC 사진·대용량 사진 업로드도 같이 확인 권장

## 3. 유예된 개선 항목 (급하지 않음)

- 과거 리포트 20건 고정, 페이지네이션 없음 (`src/lib/coach-reports.ts`) — 주 1회 사용이면 5개월치
- `/coach` 초기 목록 로딩 중 분석 버튼 활성 → 드물게 새 리포트가 목록에서 덮일 수 있음
- 일일 한도 동시 요청 레이스(TOCTOU) — 1인 앱이라 무시
- `generateAnalysis`의 텍스트 추출/실패 분기를 순수 함수로 빼면 테스트 커버리지 확대 가능
- 기존 백로그: toNum/스탯 3필드 컴포넌트 중복(3개 페이지), OCR 워커 terminate, workouts 인덱스 등
